# 可研报告精读工具 Windows 使用说明

这是一个在客户电脑本地运行的可研报告精读工具。客户不需要部署公网服务器，上传的报告、解析结果和导出的 Word 文件都保存在本机。AI 分析和政策核验会调用已配置的第三方模型接口，所以电脑需要能联网。

## 这个工具能做什么

- 上传 Word、PDF、图片格式的可研报告。
- 生成报告摘要、报告修改建议、具体解决方案。
- 专项审查经济测算、税务口径、经营模式、IRR 结论和漏项。
- 列出需要补充或核验的最新数据。
- 给出同类企业或相似业务的参考方向。
- 支持多份报告交叉比对。
- 一键导出 Word 结果。

## 支持的文件

- Word：`.docx`、`.doc`
- PDF：普通 PDF、部分扫描 PDF
- 图片：`.png`、`.jpg`、`.jpeg`、`.webp`、`.tif`、`.tiff`、`.bmp`

说明：

- `.docx` 文件可以直接解析。
- 旧版 `.doc` 文件在 Windows 上需要安装 LibreOffice，工具会调用 LibreOffice 做临时转换。
- 扫描 PDF 和图片 OCR 需要安装 Tesseract OCR。没有安装时，普通 Word 和带文字层的 PDF 仍然可以用。

## 一、客户电脑需要先安装什么

如果拿到的是正式客户安装包，正常使用不需要预先安装 Python，也不需要安装 Node.js。

安装包内会包含：

- `LocalReportReader.exe`
- 已构建好的前端页面
- 启动脚本
- `.env` 配置文件

### 1. 可选：LibreOffice

如果需要处理旧版 `.doc` 文件，请安装 LibreOffice：

```text
https://www.libreoffice.org/download/download-libreoffice/
```

安装后如果 `.doc` 仍然无法解析，建议把 `.doc` 文件用 Word 另存为 `.docx` 后再上传。

### 2. 可选：Tesseract OCR

如果需要处理扫描 PDF 或图片，请安装 Tesseract OCR。

如果不处理扫描件，可以先不安装。

## 二、解压项目

把收到的压缩包解压到一个固定目录，例如：

```text
D:\local-report-reader
```

不要直接在压缩包里双击运行。必须先解压。

## 三、检查 AI 密钥

交付包里已经包含 `.env` 配置文件，正常情况下不需要客户自己新建。

如果后续需要更换密钥，可以手动操作：

1. 打开项目文件夹。
2. 找到 `.env`。
3. 用记事本打开 `.env`。
4. 把第一行改成新的硅基流动 API 密钥。

配置格式如下：

```text
OPENAI_API_KEY=硅基流动API密钥
OPENAI_BASE_URL=https://api.siliconflow.cn/v1
OPENAI_MODEL=deepseek-ai/DeepSeek-V3
ECONOMIC_AUDIT_MODEL=deepseek-ai/DeepSeek-R1
OPENAI_API_STYLE=chat_completions
MAX_AI_CHARS=32000
AI_TIMEOUT_SECONDS=240
```

模型分工：

- `OPENAI_MODEL`：用于标准摘要、报告修改建议、多报告对比。
- `ECONOMIC_AUDIT_MODEL`：用于经济测算、IRR 和税务专项审查。

如果硅基流动账号不能使用 `deepseek-ai/DeepSeek-R1`，请把 `ECONOMIC_AUDIT_MODEL` 改成账号可用的模型。系统不会生成虚假的替代结论。

## 四、安装并启动工具

进入项目文件夹，直接双击根目录里的：

```text
install-and-start.bat
```

正式客户安装包会直接启动，不需要安装 Python 或 Node.js。请保持网络连接，因为 AI 分析需要访问模型接口。

启动成功后，通常会弹出一个后端命令行窗口：

- 后端窗口

请不要关闭这个窗口。关闭后网页会停止访问。

浏览器会自动打开：

```text
http://127.0.0.1:8787/
```

如果浏览器没有自动打开，请手动复制上面的地址到浏览器。

## 五、上传报告并生成结果

1. 点击页面上的“上传 Word、PDF、图片报告”。
2. 选择要分析的报告文件。
3. 上传完成后，左侧会出现报告名称。
4. 点击“生成精读”。
5. 等待 AI 分析完成。

长报告可能需要几分钟。等待期间不要关闭网页、后端窗口或前端窗口。

生成后会看到这些模块：

- 标准摘要
- 报告修改建议与解决方案
- 最新数据补充与核验清单
- 同类企业对比与业务建议
- 经济测算专项审查
- 精读结论
- 输出完整性检查

## 六、重点看哪些结果

建议优先看这三块。

### 1. 报告修改建议与解决方案

这里会告诉你：

- 报告哪里需要改。
- 应该怎么改。
- 需要客户补什么材料。
- 需要补充哪些最新数据。
- 哪些内容需要人工核验。

### 2. 经济测算专项审查

这里会重点判断：

- 财务测算是否正确。
- 如果不正确，错因在哪里。
- 税收口径是否完整。
- 经营模式是否支撑收入和利润。
- IRR、投资收益率、净利润、现金流口径是否一致。
- 是否缺少客户、汇率、关税、库存、坏账、资金占用、合规成本等项目。

### 3. 最新数据补充与核验清单

这里会列出：

- 需要补充的数据名称。
- 数据用途。
- 建议来源。
- 建议更新频率或截至日期。
- 是否需要联网核验或人工核验。

## 七、导出 Word

点击页面里的“导出 Word”。

导出文件会保存在：

```text
项目文件夹\data\output
```

例如：

```text
D:\local-report-reader\data\output
```

导出的 Word 可以继续人工修改，也可以作为交付客户的初稿。

## 八、手机访问

手机和电脑需要连接同一个 Wi-Fi。

电脑页面上会显示“手机扫码访问”的二维码。用手机扫码即可打开。

如果二维码没有显示，可以在手机浏览器输入页面显示的局域网地址，例如：

```text
http://192.168.x.x:8787/
```

具体地址以页面显示为准。

## 九、多报告对比

如果需要对比两份或更多报告：

1. 在左侧勾选要对比的报告。
2. 点击“交叉比对”。
3. 查看一致性信号、矛盾点、预期差地图和业务建议。
4. 如需保存，点击“导出对比 Word”。

## 十、关闭工具

关闭方式：

1. 关闭浏览器页面。
2. 回到后端命令行窗口。
3. 按 `Ctrl + C`。
4. 看到提示后输入 `Y` 并回车。

下次使用时，重新双击：

```text
install-and-start.bat
```

## 常见问题

### 1. 双击脚本后提示没有 Python

正式客户安装包正常不应该出现这个提示。这个提示说明包里缺少 `LocalReportReader.exe`，客户拿到的是源码包或不完整包。

解决方法：更换为包含 `LocalReportReader.exe` 的正式客户安装包。只有源码开发模式才需要安装 Python。

### 2. 双击脚本后提示没有 npm

如果使用的是客户安装包，正常不应该出现这个提示。这个提示说明包里缺少 `frontend\dist` 构建产物，或者客户拿到的是源码开发包，不是客户安装包。

解决方法：更换为包含前端构建产物的客户安装包。只有开发源码模式才需要安装 Node.js LTS。

### 3. 生成精读失败

常见原因：

- AI 密钥没有填写。
- AI 密钥无效或余额不足。
- 当前模型不可用。
- 网络无法访问硅基流动接口。
- 报告太长，模型响应超时。

系统不会生成本地替代结论。请先检查 `.env`、网络和模型配置，再重新点击“生成精读”。

### 4. `.doc` 文件解析失败

Windows 处理 `.doc` 需要 LibreOffice。可以安装 LibreOffice 后重试。

更稳妥的做法是：用 Word 打开 `.doc`，另存为 `.docx`，再上传 `.docx`。

### 5. 扫描 PDF 或图片没有识别文字

这通常是因为没有安装 Tesseract OCR，或者图片太模糊。

解决方法：

- 安装 Tesseract OCR。
- 提高扫描清晰度。
- 尽量上传带文字层的 PDF 或 Word 文件。

### 6. 手机打不开

检查：

- 手机和电脑是否在同一个 Wi-Fi。
- 电脑防火墙是否拦截了端口。
- 手机输入的地址是否和页面二维码下方显示的一致。

### 7. 为什么有些政策显示需要核验

工具不会把未确认的政策写成已确认依据。没有自动命中官方来源时，会标注需要核验。最终报告交付前，建议人工确认政策名称、有效期和适用范围。

## 数据保存位置

所有数据都保存在项目文件夹下：

```text
项目文件夹\data
```

其中：

- 上传文件：`data\uploads`
- 导出 Word：`data\output`
- 本地数据库：`data\reports.db`
